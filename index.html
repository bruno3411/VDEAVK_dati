Funkcionālās prasības⌄
Kopējā informācija
  • ✓ Personas vārds, uzvārds un kods augšā, ja nav "Par sevi"
  • ✓ Teksts: "Tiek attēloti personas dati Invaliditātes komisijā:"
  • ✓ Ja nav datu → "Par šo personu VDEĀVK nav reģistrētu datu"
Iesniegumi
  • ✓ Aktīvi — ja ir aktīva atbilde (spēkā esošs lēmums/atzinums). Tukšs → "Jums nav aktīvu iesniegumu"
  • ✓ Neaktīvo bloks noņemts — rādā tikai aktīvos
  • ✓ Sakārtoti pēc datuma — jaunākie pirmie
  • ✓ Poga TĀLĀK zem aktīvajiem → pāriet uz nākamo cilni
  • ✓ (?) pie Aktīvi ar paskaidrojumu
Lēmumi
  • ✓ "Aktīvi" → SPĒKĀ ESOŠIE LĒMUMI. Aktīvi: datums intervālā [no–līdz] UN Invaliditāte=Ir (Uz mūžu=2999.12.31); VAI Datums < šodien+1mēn UN Invaliditāte=Nav. Tukšs → paziņojums. Neaktīvi — pārējie; ja nav → bloku neattēlo
  • ✓ Darbspējas zaudējums: rādās tikai ja cēlonis ir Arodslimība / Nelaimes gadījums darbā / Černobiļas cēloņi (3 varianti)
  • ✓ Funkcionālo traucējumu veids: rādās tikai ja FTV satur "Redzes"
  • ✓ Ja Invaliditāte nav noteikta → slēpj Grupu, Cēloni, FTV, Periodu, Spēkā līdz
  • ✓ DNL 26 nedēļas (periods ≤182 dienas) → slēpj "Datums no"/"Datums līdz"
  • ✓ Poga TĀLĀK zem spēkā esošajiem
  • ✓ Pārsūdzēt poga noņemta
  • ✓ (?) pie grupām
Atzinumi
  • ✓ "Aktīvi" → SPĒKĀ ESOŠIE ATZINUMI. Aktīvi: datums intervālā [no–līdz] UN Noteikt. Tukšs → paziņojums. Neaktīvi — pārējie; ja nav → neattēlo
  • ✓ Ja veids = "Pārejoša darbnespēja pēc 26. nedēļas" → rāda "Atzinuma pieņemšanas datums", slēpj darbības periodu
  • ✓ Poga TĀLĀK zem spēkā esošajiem
  • ✓ (?) pie grupām
Apliecības
  • ✓ "Aktīvi" → SPĒKĀ ESOŠĀS APLIECĪBAS. Aktīvi: šodien intervālā [no–līdz]. Tukšs → paziņojums. Neaktīvi — pārējie; ja nav → neattēlo
  • ✓ Poga "Pieprasīt atkārtotai izsniegšanai": ja aktīva UN nav jau iesniegts. Nospiežot → atveras iesniegums ar atzīmētu apliecību
  • ✓ Poga TĀLĀK zem spēkā esošajām
